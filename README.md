# School of Belonging AR

A marker-based AR experience designed for direct HTTPS hosting on GitHub Pages. The camera tracks the printed marker, so the eight school areas remain anchored in space and change scale as viewers move nearer or farther away.

## Publish with GitHub Pages

1. Push these files to the `main` branch of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Set **Source** to **Deploy from a branch**, choose `main`, and choose `/(root)`.
4. Save. GitHub will provide the public HTTPS URL for your QR code.

Open the QR destination directly in Safari or Chrome, allow Camera access, then point the camera at the printable `marker.html` page. Keep the marker visible and well lit while exploring.
