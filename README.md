# AR Camera Model

A p5.js camera-overlay experience designed for direct HTTPS hosting on GitHub Pages.

## Publish with GitHub Pages

1. Push these files to the `main` branch of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Set **Source** to **Deploy from a branch**, choose `main`, and choose `/(root)`.
4. Save. GitHub will provide the public HTTPS URL for your QR code.

Open the QR destination directly in Safari or Chrome and allow Camera access.
